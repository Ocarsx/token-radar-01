How the value is worked out

Implied value = TVL × category ratio × growth factor × age factor. The category ratio is the median market-cap / TVL of the protocols in the same category whose token already trades (the comparables below). The growth factor follows the 7-day TVL change; the age factor follows how long the protocol has run with no token recorded. Nothing is hardcoded by name — every figure comes from the snapshot.

“Pre-token” means the snapshot records no token for the protocol — never that it has none. Wrapped, staked, bridged and exchange products are left out: they are not launches of their own.
